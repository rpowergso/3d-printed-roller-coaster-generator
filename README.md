# Legacy Fusion track importer

This repository preserves the original Fusion importer, manifest and icon. Its source is unchanged by the 2026-11-05 software sync.

The current standalone Coaster Studio workflow lives in [nolimits2-steel-support-generator](https://github.com/rpowergso/nolimits2-steel-support-generator), linked from the [parent project](https://github.com/rpowergso/3dPrintedRollerCoaster). It generates separate printable track/tie/support STLs from the NL2 spline without requiring this Fusion script.

Use the current app's README and fit-kit dimensions for the 1:30 corkscrew MVP. Values embedded in this legacy script are not the selected current preset. The current standalone generator's checks do not validate this script inside Fusion. Keep this history available for reference and comparison.
